The bundled/generated owly-desktop-helper is built from this revision plus
patches/desktop-events.patch, which adds structured desktop discovery, receiver
request/response events, and sender progress/delivery events.

Rust dependencies and versions are recorded in that upstream revision's
Cargo.lock. Their respective licenses continue to apply. The build script uses
--locked. The Python frontend depends on separately installed PySide6,
dbus-python and PyGObject; their packages retain their own licensing terms.

AirDrop is named only to describe interoperability with Apple's file-transfer
protocol. This is an independent project, not an Apple product.
